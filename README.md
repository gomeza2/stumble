# DESAFÍOS IMPOSIBLES

Arcade web de minijuegos rápidos con React, TypeScript, Vite y Tailwind CSS.

## Ejecutar
1. Instalar Node.js 20 o superior.
2. Ejecutar `npm install`.
3. Ejecutar `npm run dev` y abrir la URL que indique Vite.
4. Comprobar la compilación con `npm run build`.

Incluye diez minijuegos interactivos, cinco modos, progresión local, sonidos opcionales, tutorial y diseño responsive. Las estadísticas se guardan en localStorage. El ranking de esta primera versión es local; un ranking compartido necesita backend.
